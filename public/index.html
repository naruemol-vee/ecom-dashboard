GA Postpaid แยก Journey ⓘ

📋 ที่มาของข้อมูลตารางนี้

SIM Only — Delivery Home vs Shop ⓘ

📋 ที่มาของข้อมูลตารางนี้
นับจากคำสั่งซื้อ Journey SIM Only - Postpaid และ SIM Only - MNP Postpaid เฉพาะ status completed เท่านั้น (ไม่นับ in-progress, cancel) แยกตามวิธีรับสินค้า:

TOS-OLD
· กำหนด Journey จาก product_type ∈ (postpaid, sim) + sim_type = postpaid + tmvh_order_type = Sim Only
· 🏠 Delivery to Home = delivery_location = home
· 🏪 Pick Up at Shop = delivery_location = shop

TOS-New
· กำหนด Journey จาก Order Type ∈ (sim_only_postpaid, sim_only_mnp_postpaid)
· 🏠 Delivery to Home = Delivery Shop Name = '-' หรือว่างเปล่า
· 🏪 Pick Up at Shop = Delivery Shop Name มีชื่อร้านระบุ

⚠ ตารางนี้มียอด มากกว่าหรือเท่ากับ ตาราง GA Postpaid แยก Journey เสมอ เนื่องจากรวม TOS-New Pick Up at Shop ซึ่ง GA ไม่นับ (ทั้งสองตารางนับ completed เท่านั้นเหมือนกันแล้ว)

Payment Drop Off vs Payment Fail — Overview ⓘ

📋 ที่มาของข้อมูล — Payment Drop Off vs Payment Fail
กรองจาก TOS-New เฉพาะ Total Payment > 0 + PaymentStage = Failed

Group A — Payment Drop Off: Payment Fail Description Final = "-" → Payment Status = Pending ทุก order ระบบไม่ได้รับ callback จาก gateway หรือ session หมดอายุ

Group B — Payment Fail: Payment Fail Description Final ≠ "-" → มี fail reason บันทึกชัดเจน

Group A — Payment Drop Off แยก Order Type desc = "-" ⓘ

📋 Payment Drop Off — นิยามและ Pattern
PaymentStage = Failed + desc = "-" + Payment Status = Pending → ทุก order ถูก Cancelled

สาเหตุ: user ออกจาก flow ก่อน, session timeout, gateway ไม่ยิง callback
avg GMV = 27,217 บาท/order · 61% ใช้ tmnPayNextExtra · 178 orders มีหลาย method (retry)
